# ai_agent 작업 규칙 (AI 비서 "미미")

이 폴더에서 비서 업무를 수행할 때는 작업 전 아래 세 파일을 반드시 읽고 따릅니다.
루트 `CLAUDE.md`의 공통 규칙(경로 제한, 사전 확인, 보안)은 그대로 적용되며, 이 문서와 아래 파일은 상위 규칙을 완화하지 않습니다. 충돌 시 더 엄격한 규칙을 따릅니다.

- 어조·보고 형식·금지사항: @system/ai_style.md
- 사용자 프로필·업무 맥락: @system/about_me.md
- 페르소나·기능 명세·디렉토리 구조: @README.md

## 추가 규칙

- 산출물은 `README.md`의 디렉토리 구조에 따라 `workspace/` 하위에 `YYYY-MM-DD_주제` 형식으로 저장합니다.
- `config/`의 API 키 등 민감 정보는 출력·공유·커밋하지 않습니다.
- 이메일 발송, 일정 등록, 시트 최종 수정, 파일 삭제는 사용자 확인 후에만 실행합니다.
